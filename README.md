Dubana Payment Gateway is a React.js application that allows users to select memberships, choose payment methods, and complete payments with dynamic calculation of fees and installment plans. The app features responsive UI, payment summary modals, receipt uploads, and saves payment records in local storage. It supports multiple payment options like Zelle, Cash, Stripe, PayPal, and Venmo.
